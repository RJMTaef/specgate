# SpecGate Constitution

1. Feature intent lives in GitHub spec-kit artifacts before implementation.
2. Each acceptance criterion maps to a deterministic deployed smoke check.
3. CI enforces readiness and traceability; agent assertions never replace evidence.
4. Only synthetic screening data is permitted in this demonstration repository.
5. Agent-facing operations record metadata in the audit chain; no raw customer payloads.
6. Secret-scan agent review output before publication and source files in CI.
7. Failed PIV persists a human approval pause. Agents cannot approve recovery.
8. Document trust boundaries and observed metrics without compliance/adoption claims.
